💬 Messages / In Wire 확인

Wire-In 주문이 들어오면 Messages와 In Wire 카운터가 올라갑니다. 수시로 확인하세요!
  1. Messages 열기 → 내용 확인 (받는 분, 주소, 배송일, 특별지시)
  2. Mark Read 클릭
  3. In Wire로 이동 → 주문 검토 후 Accept
  4. Accept 후 To Be Designed로 이동 + SuperTicket 자동 출력 (Register 1)
Reject는 매니저 승인 없이 절대 누르지 마세요.

SuperTicket 예시 – 디자인 시작 전 반드시 출력된 티켓을 확인하세요.
